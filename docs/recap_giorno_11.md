# Recap Giorno 11

## Obiettivo
Aggiungere un nuovo microservizio **FastAPI** chiamato `data-processor` per la gestione dello scraping dei dati.

## Attività completate

- **Creazione della struttura iniziale del progetto**:
    - Creato il microservizio nella directory dedicata.
    - Aggiunto uno script per automatizzare la creazione di un ambiente virtuale Python (`venv`).

- **Implementazione di un endpoint di test**:
    - Creato un file base per il server FastAPI con un endpoint di test per verificare il corretto funzionamento del server.

- **Aggiornamento del file `.gitignore`**:
    - Aggiunti i pattern per ignorare gli artefatti specifici di Python (es. `__pycache__`, `.venv`, ecc.).

- Un microservizio FastAPI funzionante con una struttura iniziale pronta per essere estesa.
